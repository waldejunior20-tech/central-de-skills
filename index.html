Instalar ≠ Usar — os dois passos que confundem
PASSO 1 · INSTALAR

Colocar a skill no Claude

No Claude Code, o botão ⬇ instalar copia o comando pronto. Cole no terminal.

# cole no terminal:
npx skills add https://github.com/obra/superpowers

⚠ git clone só baixa os arquivos — não registra a skill.

PASSO 2 · USAR

Ativar como comando

Depois de instalada, chame com /nome-da-skill ou só descrevendo a tarefa.

# vira comando após instalar:
/superpowers  planeja e executa

🔎 Skills sem link direto têm botão de busca no GitHub.
